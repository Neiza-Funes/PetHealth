PetHealth - Avance 1
====================

Estudiante: Neiza Funes

Objetivo de este avance:
- Crear la base inicial de PetHealth.
- Trabajar con Java + XML.
- Usar Groovy DSL para Gradle.
- Minimum SDK: API 29 (Android 10.0).
- Tener una sola Activity y una sola pantalla.
- Mostrar el título "PetHealth".
- Mostrar el texto "Cuida la salud de tus mascotas".
- Mostrar un botón "Comenzar" sin funcionalidad todavía.

Archivos principales de este avance:

1. MainActivity.java
   Es la parte Java de la primera pantalla.
   En este avance solamente carga el archivo activity_main.xml.

2. activity_main.xml
   Contiene lo que se ve en pantalla: título, frase y botón.

3. strings.xml
   Guarda los textos principales de la aplicación.

4. colors.xml
   Guarda los colores sencillos usados en la pantalla inicial.

IMPORTANTE:
- El botón Comenzar todavía NO realiza ninguna acción.
- No se agregaron perfiles de mascotas, vacunas, historial médico, citas,
  recordatorios, base de datos, RecyclerView, Room, Fragments ni notificaciones.
- Estas características quedan reservadas para avances futuros.

Cómo abrirlo:
1. Descomprime PetHealth_Avance1.zip.
2. Abre Android Studio.
3. Selecciona Open y abre la carpeta PetHealth_Avance1.
4. Si aparece "Trust and Open Project", puedes elegir Trust Project.
5. Espera a que Gradle termine de sincronizar.
6. Selecciona un emulador con Android 10.0 (API 29) o superior.
7. Presiona Run.

GitHub:
Primero conviene comprobar que el proyecto abre y se ejecuta correctamente.
Después se puede crear el repositorio PetHealth y preparar las ramas main, dev y Avance-1.
